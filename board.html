N1 — Check media_log schema; write idempotent one-off Netflix import script (dedupe on title+type).
N1 · media_log has no source/tag column (id, user_id, category, title, rating numeric(3,1), note, status, added_date, created_at) and no unique constraint on title+category -- so dedupe has to happen in the script, not the DB. CSV titles contain unquoted commas ("House, M.D.", "Manhunt: The Liar, the Thief, the Conman") so parsing splits from the right (last_watched/source/status/rating/type are always simple, everything before that is the title) rather than a naive comma-split -- verified against all 86 rows with zero bad-rating or mis-parsed-type rows before touching the DB. Script queries all existing media_log rows for the user first, builds a title+category lookup, and updates in place on a match instead of inserting -- "netflix" goes into note since there's no dedicated source column.
